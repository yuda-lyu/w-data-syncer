觀察回調函數，於內部事件發生當下同步呼叫，傳入一個凍結之事件物件 { type, ... }，供測試以事件(而非等待時間)同步與診斷。type 為 'tick' 時為每次計時觸發(含 n 為累計第幾次觸發自 1 起，locked 為上一輪尚未結束而跳過本輪，為 true 時不會有後續 begin)；'begin' 時為一輪同步開始(含 round 為第幾輪自 1 起，只計實際執行之輪，跳過者不計)；'emit' 時為即將發送一個事件(含 round，name 為事件名稱 'insert'、'save'、'del'、'add'、'modify'、'remove'、'change'、'change-all'，kind 為 name 是 'change' 時之 type 否則為 null，size 為該事件 items 筆數，name 是 'change-all' 時為 null)；'fail' 時為一輪同步出錯且即將發送 error 事件(含 round，msg 為錯誤訊息字串，不傳出 Error 物件，請由 error 事件取得)；'done' 時為一輪同步結束且鎖已釋放(含 round，ok 為是否未出錯，b 為該輪是否有異動，bErr 為同步函數是否回報錯誤旗標)；'clear' 時為 clear 被呼叫(僅首次)。clear 後不再通知任何事件，進行中之輪的後續事件亦然。回調不帶接收者呼叫，其拋錯與回傳值(含回傳 Promise 之 rejection)皆忽略，不影響同步，預設 null
Returns:

回傳事件發送器並提供 clear 函數停止同步。mode='by-orm' 可監聽 insert、save、del、change、change-all 事件；mode='by-buffer' 可監聽 change-all 事件；mode='by-1to1' 或 'by-nto1' 可監聽 add、modify、remove、change、change-all 事件；各模式皆可監聽 error 事件
